# Code of Conduct

## Our Standards

This is a personal fleet project. Contributions are welcome and must be:

- Technically focused and constructive
- Respectful in code review and issue discussions
- Honest about bugs, limitations, and trade-offs

## Unacceptable Behavior

- Harassment or personal attacks
- Deliberately introducing security vulnerabilities
- Committing secrets, credentials, or private data

## Enforcement

Issues can be closed or contributors removed at the maintainer's discretion.
