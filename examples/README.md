# Examples

Usage examples for aiwatcher-mcp.

| File | Description |
|------|-------------|
| `poll_and_distill.py` | One-shot: poll all feeds, score new items with Claude |
| `add_custom_feed.py` | Add a new RSS feed programmatically |
| `query_top_items.py` | Query the top-scored items from the last 24 hours |
| `trigger_alert.py` | Manually fire the alert pipeline |
| `mcp_client_usage.md` | How to call aiwatcher tools from another MCP client |
